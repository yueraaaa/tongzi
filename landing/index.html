教室通知系统

一款面向学校的局域网通讯工具。老师在办公室发送通知， 教室电脑自动全屏展示并语音朗读，支持摄像头实时查看教室画面。

核心功能

专为学校场景设计，简单、高效、零学习成本

📢

即时通知推送

老师在办公室输入通知内容，选择目标班级，一键发送。教室电脑全屏展示通知文字，无需学生操作。

🔊

自动语音朗读

通知到达时自动调用 Windows 系统语音引擎，用标准普通话朗读通知内容，确保每位学生都能听到。

📷

静默摄像头监控

老师可随时查看任意在线教室的摄像头画面，教室端无任何提示，学生完全不知情。

技术栈

轻量高效，教室端打包仅 8MB

🟢

Node.js + Socket.IO

服务端实时消息推送，毫秒级延迟，支持断线自动重连。

⚛️

React + TypeScript

教师端 Web 界面，响应式设计，支持多教室管理与消息历史。

🦀

Tauri (Rust)

教室端桌面应用，常驻系统托盘，内存占用仅 ~25MB。

🔊

Web Speech API

调用浏览器内置语音引擎，支持中文普通话离线朗读。
