一、快速开始

系统要求

  • 教师端：Windows 10/11，无需安装 Node.js（已打包为 exe）
  • 教室端：Windows 10/11（自带 Edge WebView2），需从源码构建
  • 网络：教室电脑和办公室电脑需在同一局域网内

5 分钟部署

第一步：教师端启动

下载 教室通知-教师端.exe，双击运行。服务端自动启动，浏览器自动打开发送页面。

第二步：配置班级

在发送页面输入班级名称（如"1班""2班"），点击「+ 添加班级」。

第三步：教室端连接

在教室电脑上安装教室端程序，右键托盘图标 → 设置 → 填入教室名称和教师端 IP 地址。

第四步：发送通知

在教师端勾选目标班级，输入通知内容，按 Enter 发送。教室电脑即刻全屏展示。

二、教师端使用

界面概览

教师端是一个 Web 页面，包含以下区域：

  • 顶部状态栏：显示在线教室数量和名称
  • 教室管理面板：添加、编辑、删除班级，查看在线状态
  • 发送区域：输入通知文字，按 Enter 发送
  • 发送历史：查看所有已发送的通知记录

教室管理

  • 添加：在输入框中输入班级名称（如"三年级1班"），点击「+ 添加班级」
  • 重命名：点击班级右侧 ✏️ 图标，输入新名称后按 Enter
  • 删除：点击 🗑️ 图标，确认后删除
  • 全选：点击顶部「全选」按钮一键勾选所有班级
💡 提示：班级名称会保存在浏览器本地，下次打开无需重新添加。

发送通知

  1. 勾选要接收通知的班级（支持多选）
  2. 在下方的输入框中输入通知内容
  3. 按 Enter 键或点击「发送」按钮
  4. 消息即时推送到教室电脑，全屏显示并自动朗读
💡 提示：如果目标教室不在线，消息会发送失败并显示错误提示。请确保教室端已启动并连接到同一局域网。

三、教室端部署

构建教室端程序

教室端需要在 Windows 电脑上使用 Tauri 构建：

  1. 克隆项目：git clone https://github.com/yueraaaa/tongzi.git
  2. 进入目录：cd tongzi/receiver-tauri
  3. 安装依赖：npm install
  4. 构建安装包：npm run tauri build

构建产物位于 src-tauri/target/release/bundle/msi/，双击安装即可。

⚠️ 注意：教室电脑需安装 Edge WebView2（Win10/11 已内置），首次构建需要 Rust 工具链。

配置教室端

  1. 安装后，教室端会在系统托盘显示图标
  2. 右键托盘图标 → 选择「设置...」
  3. 填入教室名称（须与教师端配置的名称一致）
  4. 填入教师端 IP 地址和端口（如 192.168.1.100:3000）
  5. 点击「保存并重连」

开机自启

将教室端快捷方式放入 Windows 启动文件夹即可实现开机自启：

按 Win+R，输入 shell:startup，将教室端快捷方式拖入即可。

四、摄像头监控

⚠️ 重要提示：摄像头功能仅用于教学管理目的。大多数笔记本摄像头有硬件指示灯，打开摄像头时 LED 会亮起。请在合法合规范围内使用。

如何使用

  1. 在教师端教室列表中，在线教室右侧会出现 📷 图标
  2. 点击 📷 图标，下方弹出实时画面面板
  3. 摄像头画面约 3 帧/秒，自动适配窗口大小
  4. 按 Esc 键或点击「关闭」按钮停止查看

隐私说明

  • 教室端无任何提示，学生看不到正在被查看的迹象
  • 摄像头画面仅在教室端→教师端之间通过局域网传输，不经过互联网
  • 画面不保存、不录制，关闭后不留痕迹

五、常见问题

Q: 教室端显示"离线"怎么办？

检查教室电脑是否已启动教室端程序，确认教室端设置中的 IP 地址和教室名称正确，两台电脑需在同一局域网。

Q: 发送消息后教室端没有反应？

检查教师端是否显示该教室"在线"。确认防火墙未阻止 3000 端口。尝试重启两端的程序。

Q: 语音朗读没有声音？

检查教室电脑音量设置，确认 Windows 语音引擎正常工作。可在 Windows 设置 → 语音 中测试。

Q: 摄像头画面不出来？

确认教室电脑配备摄像头且未被其他应用占用。首次使用需在教室端允许浏览器访问摄像头权限（仅需一次）。

Q: 如何查看教师端 IP 地址？

教师端启动时会在控制台打印局域网 IP。也可在 Windows 命令行输入 ipconfig 查看。
